Domain

Apa itu Domain?

Domain adalah alamat unik yang digunakan untuk mengakses website di internet, misalnya www.google.com atau www.wikipedia.org. Fungsi domain adalah untuk mempermudah pengguna agar tidak perlu mengingat alamat IP server yang rumit.

Contoh: Daripada mengetik 172.217.0.46, cukup ketik google.com.
